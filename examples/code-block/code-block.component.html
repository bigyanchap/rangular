Code looks like code

A code block shows a line the way an editor does: a dark surface and a monospace face, in both themes, so a command or a snippet never reads as body text.

npm install -g @rangular/cli git clone https://github.com/bigyanchap/rangular-tutorial

Long lines scroll sideways instead of wrapping, the way an editor treats a line as one line.

node dist/packages/cli/src/cli.js build examples/code-block/code-block.component.ts --out examples/code-block/code-block.component.tsx
